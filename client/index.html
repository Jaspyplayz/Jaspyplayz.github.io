    Turnpoint

    Find the minute your League game turned.

    Overview

    Look up any League of Legends player by Riot ID. Turnpoint compares them to the opponent in their role, minute by minute, from top lane to support, and points to the moments that decided the game, with AI recaps.

    How it works

    • Pulls real match timelines from the Riot API and caches them in Supabase.
    • Charts your gold against your lane opponent and flags turning points, like a jungle gank at 8:10 that swung 1,400 gold.
    • Machine learning models trained on real match data explain why a game was won or lost.
    • Insights track habits across games, like hitting level 6 before your opponent and how often those games were won.

    Petri

    A pet that evolves from visitor ideas.

    Overview

    Petri is a self-evolving web app built by AI agents. Visitors poke, feed and name Blobby, then suggest what it should learn next. Agents turn those ideas into real code changes that ship to the live site.

    How it works

    • Each visitor idea becomes a user story with acceptance criteria.
    • An agent writes the change and its tests, then the feature map is regenerated.
    • A public timeline shows every evolution with before and after, and the files it touched.

    X Arena

    A multiplayer arena shooter on Roblox.

    Overview

    A fast first-person arena shooter built on Roblox, focused on movement that feels good and hits that feel fair online.

    How it works

    • First-person shooter movement.
    • Hitboxes are validated on the server, so clients can't fake hits.
    • Lag compensation rewinds positions so shots land where the player saw the target.
    • Code lives in files synced to Roblox with Rojo, with checks in GitHub Actions.
