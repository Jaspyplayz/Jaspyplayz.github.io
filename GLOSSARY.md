# Glossary

Terms for the portfolio overhaul (see the "Portfolio overhaul" wayfinder map in Issues).

- **Player**: Jasper, presented the way a game client presents a player profile.
- **Headline**: the one line under Jasper's name. Currently "Second-year CS at UofT. I build web apps, games and AI experiments."
- **Match history**: the list of Jasper's projects (Turnpoint, Petri, X Arena), styled as game results. Not a list of actual games.
- **Peak rank**: the highest rank Jasper reached in a game, always labelled "peak" because it is not his current rank (Grandmaster in League of Legends, Eternity in Marvel Rivals).
- **Client style**: layout and visuals modelled on the League of Legends client, without using Riot's artwork or logos.
